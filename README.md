### TourismTrends — AI-Driven Tourism Trend Analysis & Regional Prioritization

**Python | Pandas | NumPy | Statsmodels | NetworkX | PyTorch | PyTorch Geometric | Tableau**

An AI/ML-based tourism analytics framework designed to analyze tourism trends, forecast demand, identify regional patterns, and support data-driven regional prioritization.

**Key Components:**
- Time-series forecasting using SARIMA
- Tourism network analysis using NetworkX
- Regional clustering using Louvain community detection
- Graph Neural Network-based congestion prediction
- Exploratory data analysis and statistical analysis
- Tableau-based interactive visualization and decision support

[View Repository](https://github.com/SriHarshitaK/tourismtrends-ai-data-analytics)

### Brain Tumor Detection using CNN

**Python | TensorFlow | Keras | VGG19 | OpenCV | Tkinter**

Deep learning-based medical image classification system for identifying brain tumor categories from MRI scans.

**Key Components:**
- Preprocessing and augmentation of 5,000+ MRI images
- CNN-based image classification
- VGG19 transfer learning
- Image preprocessing using OpenCV
- Model evaluation and prediction
- Tkinter-based graphical inference interface

**Result:** Achieved 92% classification accuracy.

[View Repository](https://github.com/SriHarshitaK/BrainTumor-detection)
